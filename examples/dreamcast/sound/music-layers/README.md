# Original four-layer resident MIDI fixture

Requires the experimental bank-layer capability. Builds four original looping
PCM samples and an explicit ABKv2 instrument; claims four physical channels.
Checks one note produces four held voices/tokens with four distinct configured
sample addresses through coherent channel snapshots. Exercises sustain, note-off,
release and logical quiesce. The played bank and pool remain retained afterwards.
No simultaneous onset, audio-quality, physical retirement or shutdown claim.
This example intentionally remains alive for external observation.
