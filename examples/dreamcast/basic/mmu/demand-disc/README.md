# First read from disc on a page fault

Source the environment for this checkout and build the normal kernel first.
From this directory run `make` (or `gmake`), or `make disc DISC_DIR=/absolute/new/directory`
after building `utils/scramble`. The disc target uses macOS hdiutil to master
the image, with original data generated by the resident-file example. Boot
the resulting CUE with MMU support and direct CD-ROM. A successful run emits
`DP1DISC PASS cold=3 tail=1 reload=1` on SCIF.

The first dereference of each admitted range faults. The checks cover bytes,
the final partial page and zero tail, preserved errno, refusal to evict during
the use, then ending the use and reloading an evicted page from disc. The
preflight uses a separate temporary mapping, not a file prefetch. The printed
stack high-water is for the whole example thread, including file setup.
Read the closed-profile requirements in `addons/libvmdemand/README.md` before
using this in another application.
